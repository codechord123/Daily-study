# 「나의 작은 별」 아침 학습 앱 안내 (가정 안내문 초안)

학부모님께,

우리 반은 매일 아침 약 15분 동안 「나의 작은 별」 앱으로 그날의 공부를 짧게 복습합니다. 아이들은 수학·영어·국어·사회·과학 문제 20개를 풀고, 받은 별가루로 자기 별과 캐릭터를 꾸밉니다.

## 저장하는 정보
| 저장하는 것 | 내용 |
|---|---|
| 학급 번호와 별명 | 실명은 저장하지 않습니다. 선생님이 정한 별명(예: 새벽여우)으로만 표시됩니다 |
| 비밀번호 | 학생이 정한 비밀번호. Google Firebase 인증이 암호화해 보관하며 선생님도 볼 수 없습니다 |
| 학습 기록 | 날짜별 맞힌 문제 수, 과목·성취기준별 정답률, 틀린 문제와 다시 볼 문제, 학생이 '문제가 이상해요'로 알린 내용 |
| 별 꾸미기 | 별가루, 별 장식, 캐릭터 모습, 친구에게 받은 하트 수 |

이메일, 전화번호, 사진, 위치 정보는 받지 않습니다. 광고와 결제 기능도 없습니다.

## 누가 볼 수 있나요
- **학습 기록**(정답률, 틀린 문제, 다시 볼 문제)은 **학생 본인과 담임 선생님만** 볼 수 있습니다.
- **별과 캐릭터**는 같은 반 친구들이 서로 놀러 가서 볼 수 있습니다. 점수와 정답률은 친구에게 보이지 않습니다.
- 학급 코드를 아는 사람만 우리 반에 들어올 수 있습니다.

## 어디에 저장되나요
Google Firebase(Cloud Firestore)에 저장합니다. 보안 규칙으로 학급과 학생별로 읽고 쓸 수 있는 범위를 나눠 두었습니다.

## 언제 지우나요
학년이 끝나면 담임 선생님이 기록을 내려받아 학교 규정에 따라 보관하고, 앱 서버의 별과 학습 기록을 모두 지웁니다.

## 비밀번호를 잊었을 때
선생님께 말하면 '다시 가입'을 허용해 드립니다. 새 비밀번호로 가입해도 그동안의 기록은 그대로 남습니다.

문의는 담임 선생님께 해 주세요.
