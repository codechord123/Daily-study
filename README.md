# 나의 작은 별 (Daily Study)

매일 아침 미션을 풀고 별가루를 모아 나만의 3D 별과 캐릭터를 꾸미고, 추진기를 메고 친구 별로 여행하는 초등 아침 학습 앱입니다.
지금은 **5학년 2학기(2022 개정) 샘플 1개 반** 단계예요. 키 없이도 한 기기에서 바로 돌아가고, Firebase 키만 넣으면 반 전체 기기가 실시간으로 연결돼요 → [`docs/FIREBASE.md`](docs/FIREBASE.md)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ → Vercel 등에 배포
```

- 키 없음(샘플 학급): 학생은 학급 코드 `STAR5` → 번호 선택, 선생님은 **🧑‍🏫 선생님이세요?** → 비밀번호 `0000`
- 키 있음(실제 학급): 선생님은 Google 로그인 → 학급 만들기 → 학급 코드, 학생은 학급 코드 → 번호 → 비밀번호(6글자 이상)로 가입

## 학생이 하는 것

| 기능 | 내용 |
|---|---|
| 오늘의 미션 | 20문제 = 수학 6 · 영어 5 · 국어 3 · 사회 3 · 과학 3, 약 15분. 영어는 🔊 원어민 발음 듣기. 3D 별 옆에서 풀고, 맞히면 별 조각이 고리에 채워져요. 하루 1번 별가루 지급 |
| 다시 보기 | 틀린 문제·'🤔 헷갈렸어요' 누른 문제는 1·3·7일 뒤 아침 미션에 다시 나오고, 3번 이어 맞히면 졸업 |
| 난이도 맞추기 | 과목별 최근 20문제 정답률로 쉬운(1)·보통(2)·어려운(3) 문제 비율을 조절 |
| 읽어 주기 | 영어는 원어민 발음, 국어·사회·과학은 🔊 읽기로 지문·문제·보기를 우리말로 |
| ✍️ 낱말 쓰기 | `kind: 'text'` 문제는 답을 직접 써요 (띄어쓰기·문장 부호 무시, `accept` 로 다른 정답도) |
| 🌹 어린 왕자의 부탁 | 아침 미션을 마친 날 가끔(일주일에 한두 번) 어린 왕자가 별에 찾아와 이야기 속 부탁(장미·바오밥·여우·우물 등 8가지)을 해요. 내 다시 볼 문제·약한 과목에서 3문제를 풀면 한정 선물 소품과 별가루 15. 선생님은 '이번 주' 탭에서 반 모두에게 보낼 수도 있어요 |
| 🛰 문제 정거장 | 내 별 궤도를 도는 정거장을 누르면 과목별 정답률·연습, 과목별 오답 노트, 다시 볼 문제(언제 다시 나오는지) 를 한곳에서 |
| 오답 노트 | 틀린 문제가 모이고, 다시 맞히면 정복 (아침 미션 문제는 별가루 +3) |
| 별가루 | 맞힌 문제 4 · 끝까지 풀기 문제당 1 + 20 · 연속 출석 최대 20 · 다시 맞힌 문제 3 · 주 5일 개근 30 (하루 최대 250) |
| 과목별 연습 | 배운 단원까지 마음껏 연습 (별가루 없음) |
| 나의 기록 | 연속 출석, 출석 달력, 과목별 정답률 |
| 별 꾸미기 | 소품 85종(첨성대·앙부일구·측우기·거북선·현미경·비커 등 교과 연계 포함) × 색 8 × 크기 3, 별 색 16·무늬 9·고리 6·위성·빛 무리 7·주변 효과 8 |
| 내 모습 | 종족 10, 옷 9, 머리 모양 8, 머리 장식 21, 눈 6, 망토, 소품 14, 펫 16, 24색 팔레트, 🎲 랜덤 |
| 여행 | 🚀 여행 → 친구 별 골라 **⚡ 바로 가기** 또는 **🚀 날아서**(화살표 안내). 비행 중 별을 눌러 고르기, 별 근처에서 내리기/지나가기 |
| 함께 있기 | 같은 별·우주에 있는 친구가 실시간으로 보이고 이모트·하트를 주고받아요 |

조작: 별 위에서는 탭(걷기)·드래그(돌리기)·＋/－(확대), 비행은 조이스틱·▲▼ 또는 키보드(↑↓←→ · Space/Shift · Enter 착륙 · +/- 확대). 미션은 키보드 1~4, O/X, 숫자, Enter.

## 선생님 화면
- 오늘 미션 완료 수, 반 평균·과목별 정답률, 많이 틀린 단원
- 학생별 표(오늘 점수·연속 출석·과목별 정답률·남은 오답), CSV 내보내기
- **학습 분석**: 성취기준별 정답률(60% 아래 학생 수), 많이 틀린 문제 순위, 학생이 보낸 '🚩 문제가 이상해요' — 문제를 펼쳐 보고 **출제에서 빼기**
- **학생 자세히**: 표에서 학생을 누르면 성취기준별 정답률(반 평균과 비교), 최근 기록, 과목별 오답, 자주 틀린 문제와 고른 답
- **📌 아침 미션에 넣기**: 많이 틀린 문제를 골라 다음 아침 미션에 반 모두에게 (최대 5문제)
- **🌌 우리 반 이번 주**: 학급 공동 목표(주당 미션 수)와 보상, 점수 대신 꾸준함을 칭찬하는 '반짝 친구'
- **🗂 학년 정리**: 전체 기록 백업(JSON), 학년말 별·학습 기록 지우기
- **📺 수업 화면에 띄우기**: 많이 틀린 문제를 TV에 크게 띄우고 정답·풀이를 함께 보기 (←/→ 넘기기, Space 정답)
- **출제 단원**: 과목마다 단원을 고르면 그 단원(여러 개 가능)에서만 출제, 안 고르면 날짜로 자동 진도 + 복습
- 설정: 2학기 시작일, 친구 별 여행 잠금
- 시연용 **샘플 기록 채우기** (샘플 표시, 지우기 가능)

## 반 전체 연결 (Firebase)

설정 방법은 [`docs/FIREBASE.md`](docs/FIREBASE.md). 키가 없으면 각 기기 localStorage + 데모 친구로 동작하고, 키가 있으면 아래처럼 바뀌어요 (화면 코드는 그대로).

| 담당 | 키 없음 (로컬) | 키 있음 (`services/cloud.js`) |
|---|---|---|
| 학생 별·기록 `store/profileStore.js` | localStorage | Firestore `classes/{classId}/students` |
| 학급 설정 `store/classSettings.js` | localStorage | Firestore `classes/{classId}` |
| 하트 | localStorage | Firestore `classes/{classId}/hearts` (increment) |
| 실시간 함께 있기 `services/presence.js` | BroadcastChannel + 데모 봇 | Realtime DB `presence/{classId}` |
| 로그인 `ui/CloudLogin.jsx` | 샘플 학급 코드·번호 | 선생님 Google, 학생 학급 코드+번호+비밀번호 (`classCodes`, `classes/{id}/seats`) |

보안 규칙(`firestore.rules`, `database.rules.json`): 학생은 자기 번호 별만 쓰고, 설정·명단은 담임만 바꿔요.
판매 단계에서 남은 것: 쎈에듀 로그인 연동(공개 API가 있을 때), 보상 계산을 Cloud Functions로 옮기기.

배포 계획(웹·Android·iOS)과 아이디어 메모는 `docs/ROADMAP.md`.
