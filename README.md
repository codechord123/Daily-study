# 나의 작은 별 (Daily Study)

매일 아침 미션을 풀고 별가루를 모아 나만의 3D 별과 캐릭터를 꾸미고, 추진기를 메고 친구 별로 여행하는 초등 아침 학습 앱입니다.
지금은 **5학년 2학기(2022 개정) 샘플 1개 반** 단계예요. 키 없이도 한 기기에서 바로 돌아가고, Firebase 키만 넣으면 반 전체 기기가 실시간으로 연결돼요 → [`docs/FIREBASE.md`](docs/FIREBASE.md)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ → Vercel 등에 배포
```

- 학생: 학급 코드 `STAR5` → 번호 선택 (처음 들어오면 4장짜리 안내가 나와요)
- 선생님: 로그인 화면 아래 **🧑‍🏫 선생님이세요?** → 비밀번호 `0000`

## 학생이 하는 것

| 기능 | 내용 |
|---|---|
| 오늘의 미션 | 20문제 = 수학 6 · 영어 5 · 국어 3 · 사회 3 · 과학 3, 약 15분. 영어는 🔊 원어민 발음 듣기. 3D 별 옆에서 풀고, 맞히면 별 조각이 고리에 채워져요. 하루 1번 별가루 지급 |
| 오답 노트 | 틀린 문제가 모이고, 다시 맞히면 정복 (아침 미션 문제는 별가루 +3) |
| 과목별 연습 | 배운 단원까지 마음껏 연습 (별가루 없음) |
| 나의 기록 | 연속 출석, 출석 달력, 과목별 정답률 |
| 별 꾸미기 | 소품 58종 × 색 8 × 크기 3, 별 색·무늬·고리·위성·빛 무리·주변 효과 |
| 내 모습 | 종족 10, 옷 7, 머리 모양 8, 머리 장식 17, 눈 6, 망토, 소품 11, 펫 13, 24색 팔레트, 🎲 랜덤 |
| 여행 | 🚀 여행 → 친구 별 골라 **⚡ 바로 가기** 또는 **🚀 날아서**(화살표 안내). 비행 중 별을 눌러 고르기, 별 근처에서 내리기/지나가기 |
| 함께 있기 | 같은 별·우주에 있는 친구가 실시간으로 보이고 이모트·하트를 주고받아요 |

조작: 별 위에서는 탭(걷기)·드래그(돌리기)·＋/－(확대), 비행은 조이스틱·▲▼ 또는 키보드(↑↓←→ · Space/Shift · Enter 착륙 · +/- 확대). 미션은 키보드 1~4, O/X, 숫자, Enter.

## 선생님 화면
- 오늘 미션 완료 수, 반 평균·과목별 정답률, 많이 틀린 단원
- 학생별 표(오늘 점수·연속 출석·과목별 정답률·남은 오답), CSV 내보내기
- **출제 단원**: 과목마다 단원을 고르면 그 단원(여러 개 가능)에서만 출제, 안 고르면 날짜로 자동 진도 + 복습
- 설정: 2학기 시작일, 친구 별 여행 잠금
- 시연용 **샘플 기록 채우기** (샘플 표시, 지우기 가능)

## 커리큘럼 (5학년 2학기)
- 수학: 수의 범위와 어림하기 · 분수의 곱셈 · 합동과 대칭 · 소수의 곱셈 · 직육면체 · 평균과 가능성 — 문제 자동 생성
- 사회: 나라의 등장과 발전 · 고려 · 조선과 유교 문화
- 국어: 낱말과 관용 표현 · 맞춤법과 높임 표현 · 토의·토론·발표 · 읽기와 쓰기
- 영어: 학교와 과목 · 날씨와 계절 · 건강과 음식 · 길 찾기와 장소 · 꿈과 우주 · 생활과 행사 (단어 48 + 생활 표현 18)
- 과학: 생물과 환경 · 날씨와 우리 생활 · 물체의 운동 · 산과 염기 (출판사마다 순서가 달라 선생님 화면에서 단원 지정)
- 날짜로 진도를 계산해 지금 단원 위주 + 지난 단원 복습. 문제 은행은 `src/data/missions/grade5s2.js`, 수학 생성기는 `src/engine/mathGen.js`

## 소리

## 구조

```
src/
  theme/      디자인 토큰
  data/       소품·캐릭터·학급·문제 은행
  engine/     미션 조립, 수학 생성기
  store/      useGame(학생 상태·보상), useUI(화면 상태), profileStore(저장), classSettings(학급 설정)
  services/   presence(실시간), flightInput(비행 입력), sound(소리)
  three/      3D: 별 셰이더, 캐릭터·펫·추진기, 소품, 별 장면, 우주 비행, 썸네일
  ui/         로그인, HUD, 미션, 꾸미기, 여행, 기록, 선생님 화면
```

## 반 전체 연결 (Firebase)

설정 방법은 [`docs/FIREBASE.md`](docs/FIREBASE.md). 키가 없으면 각 기기 localStorage + 데모 친구로 동작하고, 키가 있으면 아래처럼 바뀌어요 (화면 코드는 그대로).

| 담당 | 키 없음 (로컬) | 키 있음 (`services/cloud.js`) |
|---|---|---|
| 학생 별·기록 `store/profileStore.js` | localStorage | Firestore `classes/{classId}/students` |
| 학급 설정 `store/classSettings.js` | localStorage | Firestore `classes/{classId}` |
| 하트 | localStorage | Firestore `classes/{classId}/hearts` (increment) |
| 실시간 함께 있기 `services/presence.js` | BroadcastChannel + 데모 봇 | Realtime DB `presence/{classId}` |

판매 단계에서 남은 것: Google/쎈에듀 로그인과 교사 권한, 보안 규칙 좁히기, 보상 계산을 Cloud Functions로 옮기기.

배포 계획(웹·Android·iOS)과 아이디어 메모는 `docs/ROADMAP.md`.
